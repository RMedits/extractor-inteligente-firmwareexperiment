Precauciones para cables largos:
• Usar cable apantallado o par trenzado para GPIO19
• Mantener cables de señal separados de cables de potencia
• Cable de potencia grueso (AWG 20 mínimo) para reducir pérdidas
• Verificar que GND sea común entre ESP32 y MOSFET

📋 Lista de Materiales Adicionales:

Para cables de ~1 metro:
• Cable apantallado o par trenzado 2 conductores (1.5m)
• Cable de potencia AWG 20-22, 2 conductores (1.5m)
• Capacitor cerámico 100nF (código 104) x1
• Resistencia 10kΩ 1/4W x1 (ya lo tienes)
• Termoretráctil para aislar cables no usados del ventilador
• Caja pequeña o soporte para montar MOSFET + componentes
✅ Checklist de Montaje:

1. Montar MOSFET + R 10kΩ + C 100nF en caja/soporte
2. Colocar conjunto a < 30 cm del ventilador
3. Conectar cable NEGRO ventilador → MOSFET Drain (corto)
4. Tender cables desde ESP32 (1m): +12V, GND, GPIO19
5. Conectar cable apantallado GPIO19 → MOSFET Gate
6. Verificar continuidad Gate-GND = ~10kΩ
7. Test Fail-Safe: ventilador OFF con ESP32 apagado
8. Cargar código y probar control PWM
