🔧 Pasos de Montaje

⚠️ ANTES DE EMPEZAR:
1. Desconectar TODA la alimentación (12V y ESP32)
2. Descargar capacitores (cortocircuitar terminales con resistencia)
3. Trabajar con buena iluminación
Paso 1: Preparar MOSFET
• Soldar resistencia 10kΩ entre Gate (pin 1) y Source (pin 3)
• Soldar capacitor 100nF entre Gate y Source
• Verificar con multímetro: Gate-Source debe medir ~10kΩ
Paso 2: Montar en Zona Fuente (+/-)
• Fijar MOSFET cerca de tu placa de filtrado
• Usar caja pequeña o brida para asegurar
• Dejar pines accesibles para conexiones
Paso 3: Reconectar Ventilador
• Localizar cable NEGRO del ventilador (actualmente va a fuente GND)
• Cortarlo y conectar al Drain (pin 2) del MOSFET
• Cable ROJO del ventilador mantiene su conexión a +12V
Paso 4: Conectar MOSFET a GND
• Source del MOSFET (pin 3) → GND común de la fuente
• Usar cable de calibre adecuado (AWG 22 mínimo)
Paso 5: Tender Cables desde ESP32
• Pasar cable par trenzado de 2 conductores (~1m)
• Conductor 1: ESP32 GPIO19 → MOSFET Gate (pin 1)
• Conductor 2: ESP32 GND → MOSFET Source (pin 3)
• Mantener cables alejados de fuente 12V (ruido)
Paso 6: Aislar Cables No Usados
• Cable AZUL (PWM) del ventilador: cubrir con termoretráctil
• Cable AMARILLO (Tacho): dejar libre o aislar

🧪 Test de Seguridad (Fail-Safe)

Test 1: Verificación Eléctrica (sin alimentar)
Con multímetro:
• Gate-Source debe medir ~10kΩ (resistencia pull-down)
• Drain-Source debe medir circuito abierto (MOSFET OFF)
• +12V y GND deben tener continuidad con fuente

Test 2: Fail-Safe (ESP32 apagado)
1. Dejar ESP32 desconectado/apagado
2. Aplicar 12V a la fuente
3. Resultado esperado: Ventilador APAGADO
4. Si arranca → ⚠️ ERROR: revisar pull-down

Test 3: Control Manual (ESP32 encendido)
1. Cargar código del firmware
2. Encender ESP32
3. Verificar en Monitor Serial: "✓ MOSFET inicializado"
4. Probar modo manual: ventilador debe arrancar y variar velocidad

🔍 Solución de Problemas

Problema: Ventilador arranca sin ESP32
• Causa: Resistencia pull-down mal conectada o ausente
• Solución: Verificar 10kΩ entre Gate y GND con multímetro

Problema: Ventilador no arranca con código
• Causa: GPIO19 no llega al Gate, o conexión pobre
• Solución: Verificar continuidad ESP32 GPIO19 → MOSFET Gate

Problema: MOSFET se calienta mucho
• Causa: Mala conexión en Drain o Source (resistencia parásita)
• Solución: Rehacer conexiones de potencia con cable grueso

Problema: Velocidad errática o ruido
• Causa: Ruido en señal de Gate por cable largo
• Solución: Verificar capacitor 100nF Gate-Source, usar cable apantallado
